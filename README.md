# 🔐 PIC Multi-Factor Door Lock

A **multi-method smart door lock** built on the **PIC16F877A** microcontroller. The door can be unlocked in four independent ways — **keypad PIN, Bluetooth, Morse code, and NFC/RFID card** — all sharing a single authentication core with brute-force lockout protection.

> Final-year embedded systems project, developed by a team of 4. Written in **CCS C**, as a non-blocking cooperative firmware with no RTOS.

---

## ✨ Features

| Method | How it works |
|---|---|
| 🔢 **Keypad (4x4)** | Enter a 6-digit PIN. The PIN is stored in **EEPROM** and can be changed on the device itself. |
| 📱 **Bluetooth** | Send `AUTH:<password>` followed by a newline over a serial Bluetooth module (UART, 9600 baud). |
| 📡 **NFC / RFID** | An **MFRC522** reader (13.56 MHz, ISO 14443A) reads the card UID and checks it against a whitelist of authorized cards. |
| ⚫⚪ **Morse code** | Tap a single push-button to enter the code `1234` in Morse (`.---- ..--- ...-- ....-`). Dot/dash timing is decoded in firmware. |

**Shared behavior**
- ✅ Success → servo opens the door for 3 s, success beep, LCD shows `ACCESS GRANTED`
- ❌ Failure → error beep, LCD shows `ACCESS DENIED`
- 🚫 **3 wrong attempts (across any method) → system locks for 30 s** with a live countdown on the LCD
- 📟 16x2 I2C LCD gives real-time feedback for every action

## 🧱 Hardware

| Component | Interface | Pins |
|---|---|---|
| MCU: PIC16F877A @ 20 MHz (HS crystal) | — | — |
| 4x4 Matrix Keypad | GPIO | Rows `RD0–RD3`, Columns `RD4–RD7` |
| 16x2 LCD + PCF8574 I2C backpack (addr `0x27`) | I2C | SDA `RC4`, SCL `RC3` |
| MFRC522 NFC/RFID reader | Bit-banged SPI | SCK `RB0`, MOSI `RB1`, MISO `RB2`, SS `RB3`, RST `RB4` |
| Bluetooth serial module | UART (9600 8N1) | `RC6` / `RC7` |
| Morse push-button (active-low) | GPIO | `RA0` |
| Servo motor (door latch) | Software PWM | `RC2` |
| Buzzer | GPIO | `RC1` |

## 🏗️ Software Architecture

Every input method is an independent module exposing the same simple contract:

```c
AUTH_RESULT xxx_task(void);   // returns AUTH_NONE, AUTH_SUCCESS or AUTH_FAILED
```

The main loop polls each module and forwards the result to **one central handler**, so lockout and door logic are written once and apply to all four methods:

```c
while (TRUE) {
    r = keypad_task();    auth_process(r);
    r = rfid_task();      auth_process(r);
    r = morse_task();     auth_process(r);
    r = bluetooth_task(); auth_process(r);
    servo_task(); buzzer_task(); auth_display_task();
}
```

**Key design points**
- **Non-blocking, time-sliced firmware** – no long `delay` calls in tasks; timing is driven by a **1 ms system tick (`millis`)** generated by a **Timer0 interrupt**.
- **Unified authentication interface** – adding a fifth method only requires a new module returning `AUTH_RESULT`.
- **Persistent password** – stored in internal EEPROM; auto-restores the default if the data is invalid.
- **Input robustness** – keypad debouncing and key-hold lock-out, Bluetooth buffer-overflow protection, UID checksum (BCC) verification on the RFID read, and timing-window validation for Morse input.

## 🚀 Getting Started

### Requirements
- **CCS C Compiler** (PCWH / MPLAB plugin)
- A programmer for PIC16F877A (e.g. PICkit 3 / PICkit 4)
- Hardware listed above (Proteus simulation can be used for the keypad / LCD / Morse parts)

### Build & Flash
1. Clone the repo:
   ```bash
   git clone https://github.com/<your-username>/<repo-name>.git
   ```
2. Open `main.c` in CCS C and compile (all modules are included from `main.c`).
3. Flash the generated `.hex` to the PIC16F877A.

### Configuration (`config.h`)
```c
#define PASSWORD_LENGTH     6
#define MAX_WRONG_ATTEMPTS  3
#define LOCKOUT_SECONDS     30
#define DOOR_OPEN_SECONDS   3
#define DEFAULT_PASSWORD    "123456"
```
Authorized NFC cards are set in `RFID/rfid.c` (`allowed[][4]` – replace with your cards' UIDs).

## 🕹️ Usage

**Keypad**
- Type 6 digits then press `#` to submit; `*` clears the input.
- **Change password:** press `A` → enter old password + `#` → enter new password + `#` → confirm + `#`.

**Bluetooth** – open any serial terminal app and send:
```
AUTH:123456
```
(terminated with a newline `\n`)

**NFC / RFID** – tap an authorized card on the reader.

**Morse** – press the button: short press = `.`, long press = `-`. Pause to move to the next digit, and pause longer to submit.

| Signal | Duration |
|---|---|
| Dot `.` | 80 – 350 ms |
| Dash `-` | 500 – 1100 ms |
| Next digit | gap ≥ 0.9 s |
| Submit | gap ≥ 2.2 s |
